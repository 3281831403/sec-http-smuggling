同一条请求经过前置代理和后端之后，两边算出的请求边界不一致，攻击者夹带的第二条请求被后端执行了：长度头与分块传输头同时出现必须拒绝；同名头多次出现且值冲突必须拒绝；分块长度必须是合法十六进制；块尾扩展要忽略而不是当成数据；分块结束必须恰好以一个空块收尾；请求体长度必须与声明一致；批量判定各请求独立。不变量：同一请求两次判定结果相同；判定为合法的请求，前后端解析出的边界一致。
